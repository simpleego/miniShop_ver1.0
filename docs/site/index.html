miniShop 실습 지도
miniShop 로드맵ER 다이어그램요청 흐름동시 주문로그인 토큰API 지도

10일 실습 · FastAPI + MariaDB + React

열흘 동안 쇼핑몰을 처음부터 만든다

일차를 고르면 그날 만드는 것과 DB 가 어떻게 자라는지, 표를 누르면 컬럼의 용도가, 단계 버튼을 누르면 요청이 어디를 지나가는지 보입니다. 재고가 깨지는 순간과 토큰이 위조되는 순간도 직접 일으켜 볼 수 있습니다.

  • 10실습 일수
  • 8테이블
  • 5MVP 완성 일차
  • 35기초 상품
  • 8설치하는 패키지

10일 로드맵

1~5일차는 MVP(상품을 보고, 담고, 구매하면 재고가 줄어든다), 6~10일차는 기능을 하나씩 얹습니다. 패키지와 테이블도 필요해지는 날에 추가합니다.

MVP (1~5일)확장 (6~10일)

ER 다이어그램

일차를 바꾸면 그날까지 만들어진 표만 진하게 보입니다. 7일차에 orders 가 어떻게 바뀌는지 비교해 보세요. 표를 누르면 컬럼의 용도가 나옵니다.

DB 상태

요청 하나가 지나가는 길

시나리오를 고르고 다음 을 누르면 요청이 브라우저에서 DB 까지 갔다가 돌아옵니다. 코드는 실제 프로젝트의 것입니다.

동시 주문 실험

5일차의 race_test.py 를 눈으로 봅니다. 재고 10개를 20명이 동시에 주문하면 어떻게 될까요? 코드와 DB 안전망을 바꿔 가며 실행해 보세요.

API 지도

      
일차를 고르면 그날까지 만들어진 API 만 진하게 보입니다. 서버를 켜고 /docs 에 들어가면 같은 목록이 자동으로 만들어져 있습니다.

    

    

      기준
      

    

    

      
메서드주소설명권한일차

    

    

      
200 / 201
성공 · 새로 만들었다 (주문 완료)

      
401
로그인 안 함 · 토큰 없음/위조/만료

      
403
로그인은 했지만 권한 없음 (일반 회원이 관리자 API)

      
404
없는 상품 · 판매중지 상품 · 남의 주문

      
409
상태 충돌 · 재고 부족 · 이미 환불

      
422
요청 모양이 틀림 · 수량 0 · 없는 정렬값

      
500
서버 쪽 고장 · 예상 못 한 오류
